# GitHub Practice for AI·SW 2026 🚀

건양대학교 **2026 오픈소스 교육 - GitHub 활용 실습**을 위한 Repository입니다.

본 Repository에서는 Git과 GitHub의 기본적인 사용 방법을 익히고,  
직접 Repository를 **Fork**하여 파일을 수정한 뒤 **Pull Request(PR)**를 생성하는 과정을 실습합니다.

---

## 📚 실습 내용

이번 실습에서는 다음과 같은 GitHub Workflow를 직접 수행합니다.

**Fork → Clone → Add → Commit → Push → Pull Request**

| 단계 | 내용 |
|---|---|
| **Fork** | 실습 Repository를 자신의 GitHub 계정으로 가져옵니다. |
| **Clone** | Fork한 Repository를 자신의 컴퓨터로 복제합니다. |
| **Add** | 변경한 파일을 Commit 대상으로 등록합니다. |
| **Commit** | 변경사항을 하나의 버전으로 기록합니다. |
| **Push** | Commit한 내용을 자신의 GitHub Repository에 반영합니다. |
| **Pull Request** | 변경한 내용을 원본 Repository에 반영하도록 요청합니다. |
